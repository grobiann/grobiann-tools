THE MATH

켈리 공식, 그리고 짧은 증명

승률을 p, 패배 확률을 q = 1 − p, 승리 시 수익률을 a, 패배 시 손실률을 b라 하자. 매회 전체 자산의 f만큼 투자한다. 수식에서는 60%를 0.6으로 쓴다.

f* = pa − qbab = pb − qa

a > 0, 0 < b ≤ 1. 같은 확률·손익률로 독립 반복하고 매번 비중을 재조정한다고 가정한다. 미투자 현금 수익률과 차입금리는 0이며 비용·세금은 제외한다.

자산의 곱을 로그의 합으로 바꾼다

한 번 이기면 자산은 1 + af배, 지면 1 − bf배가 된다. n번 중 w번 이겼을 때:

Wₙ / W₀ = (1 + af)w(1 − bf)n−w

n이 커지면 w/n → p이므로, 1회당 장기 로그 성장률은 다음과 같다.

g(f) = p ln(1 + af) + q ln(1 − bf)

미분해서 성장률의 꼭짓점을 찾는다

g′(f) = pa1 + af − qb1 − bf = 0
pa(1 − bf) = qb(1 + af)
pa − qb = abf(p + q) = abf

따라서 f* = (pa − qb)/(ab)다. 또한,

g″(f) = −pa²(1 + af)² − qb²(1 − bf)² < 0

성장률이 오목하므로 내부의 정지점이 최대다. 공매도는 제외하되 100%를 넘는 레버리지는 허용한다. p < 1에서 f < 1/b여야 패배해도 자산이 남는다. p = 0이면 0%, p = 1이면 차입비용이 없는 이 모형에서 유한한 최적 비중이 없다. q > 0이고 bf = 1이면 전액 손실 가능성으로 g(f) = −∞다.

산술적 기댓값과 무엇이 다른가?

산술적 기댓값 E[R(f)] = f(pa − qb)는 직선이다. 켈리는 이 직선이 아니라 g(f)를 최대화한다. 그래프의 ‘기하 성장률’은 eg(f) − 1로, 같은 최적 비중을 갖는 1회당 복리 성장률이다.

결과는 입력한 확률과 손익률이 맞다는 가정하의 수학적 최적값이다. 실제 수익 보장이나 개인별 권장 비중을 뜻하지 않는다.
